

# 服务器安装
## 1 静电防护 ESD Safety
### 1.1 通用防静电操作规范
人体静电极易击穿服务器主板、存储等静电敏感元器件，开展任何硬件装配、上架、拆装机操作前，必须遵守以下规范：
1. 机房环境要求
    - 机房铺设防静电地板/地垫，配套防静电工作椅；机房隔断、窗帘采用防静电材质。
    - 机柜、机架金属外壳、落地设备可靠接地；工作台仪器统一接入公共接地端。
    - 维持机房合理温湿度，干燥环境会大幅提升静电产生概率。
2. 人员操作要求
    - 操作前摘除手表、项链、金属首饰等导电物品，穿着防静电工作服。
    - 接触板卡、硬盘等组件必须佩戴防静电腕带/防静电手套。

    ![ESD Prohibited Conductive Objects Diagram](../../../servers_img/common/esd_remove_conductive_items.png)

3. 物料存放与搬运
    - 未装配组件全程存放于防静电包装袋/防静电盒内。
    - 临时拆卸的硬件放置在防静电泡沫垫上。
4. 硬件触碰禁忌
    - 禁止直接触摸电路板焊点、芯片引脚、裸露金手指区域。

### 1.2 防静电腕带佩戴步骤
操作前确认机柜已完成可靠接地：
1. 将手腕穿入防静电腕带；

    ![ESD Wrist Strap Wearing Diagram](../../../servers_img/common/esd_wrist_strap.png)

2. 收紧锁扣，保证腕带内侧完全贴合皮肤；
3. 将腕带接地插头插入机柜ESD接地插孔。

## 2 安装工具清单 Required Installation Tools
执行服务器物理安装、拆装操作，请提前准备以下工具及防护辅料：
- 防护类：防静电腕带、防静电手套、防静电包装袋、劳保手套
- 工具类：M3 十字螺丝刀、一字螺丝刀

## 3 安装环境要求 Installation Environment
### 3.1 空间与通风要求
为保障散热与后期维护，机房部署需满足以下条件：
- 服务器仅限安装在受限出入区域。
- 保持设备周边环境整洁无杂物。
- 机柜前后预留≥800mm维护散热空间。
- 服务器进风口无遮挡，保障通风顺畅。
- 机房空调送风量满足整机散热需求。

### 3.2 温湿度标准
设备需放置在可控温湿度机房，常年配备温控、加湿/除湿设备，参数标准如下：

| 项目 | 运行标准 |
| :--- | :--- |
| 温度 | 5 ℃ ～ 40 ℃（41 ℉ ～ 104 ℉） |
| 湿度 | 8% RH ～ 90% RH（无冷凝） |

### 3.3 机柜适配要求
- 机柜符合 IEC 297 标准，19英寸标准机架，机柜深度≥800 mm。
- 机柜前门配置防尘网。
- 机柜后侧预留交流电源接入位置。
