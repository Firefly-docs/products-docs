> 表中 `√` 仅表示当前 SDK 设备树下的驱动已适配、调试通过，**并不代表 IQ（图像质量）已调好**。自动曝光、白平衡、降噪等实际成像效果取决于对应的 ISP/IQ 配置，需结合对应 SDK 确认。
>
> 以下均以 Linux 系统为主，Android 系统需结合实际 SDK 的设备树配置来确认。
