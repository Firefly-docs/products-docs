
# 接口定义

## 整机接口定义

### 硬件版本V1

Face-RK3399 V1 提供了丰富的接口，主要包括：电源接口，USB OTG接口，1 x USB3.0，USB2.0（座子×2)，以太网，TP触摸接口，WIFI天线，MIC接口，RTC电源接口，12v电源接口,5v电源接口，TF卡槽,I2C，recovery按键，调试串口，工业级串口(RS485,2TTL)，RTC电源接入口，MIPI屏接口，MINI-CSI0，MINI-CIS1，光感接口，3 x LED驱动。具体如下图：

![](../../../rk3399_img/Face-RK3399/obverse.png)
![](../../../rk3399_img/Face-RK3399/reverse.jpg)

### 硬件版本V2

Face-RK3399 新增硬件版本V2与V1版本比较有较大的更动。

主要接口包括：2 x Speaker 音频输出（4Ω 2.7W）、1 x MIC音频输入、2 路 MIPI 摄像头、支持 2 路 USB 2.0 摄像头、LED补光接口、MIPI 触摸屏×1，RTC×1(法拉电容供电)、ADC×1、Debug×1、5V 电源输出 x1、12V 电源输入 x1、 USB3.0 x 1、USB2.0 x 1、NFC 接口 x 1、身份证模块 x1、加热模块 x1、EDP 显示屏 x1、EDP 触摸 x1、RESET 按键 x1、电源按键 x1、TTL 串口 x1、雷达 x1、

![](../../../rk3399_img/Face-RK3399/obverse_V2_1.png)

![](../../../rk3399_img/Face-RK3399/reverse_V2_1.jpg)

### 4G 模块拓展板

搭载Face-rk3399 V2 硬件版本的 Face-X2采用了4G模块拓展板，
主要引出：
1） 继电器（Realy）
2） 韦根发送 x 1、韦根接收 x 1
3） RS232
4） RS485
5） USB3.0
6） USB2.0
7） 10/100M 以太网
8） DC 12V
