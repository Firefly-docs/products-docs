# 产品介绍

## WXT14R2201 WiFi/BT 模组

WXT14R2201 是一款基于 RTL8852BE-CG 芯片的双频 WiFi 和蓝牙 5.2 模组，支持 WiFi 6、2.4 GHz 和 5 GHz WiFi 频段。

![](../../../modules_img/WXT14R2201/rtl8852be_f.png)

## 规格参数

| 项目 | 参数 |
| ---- | ---- |
| 型号 | WXT14R2201 PCIe |
| WiFi | IEEE 802.11ax/ac/a/b/g/n，2T2R |
| 蓝牙 | Bluetooth 5.2 |
| 芯片 | RTL8852BE-CG |
| 接口 | WiFi: PCIe；蓝牙: USB |
| 尺寸 | 22.0 mm x 30.0 mm x 2.3 mm |
| 卡型 | M.2 2230-S3-A-E |
