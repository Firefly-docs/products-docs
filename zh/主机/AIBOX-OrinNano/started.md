# 简介

| OS 名称  | SDK 版本 | 内核版本 | 支持情况 | 维护情况 |
| :--------: | :-------: | :-------: | :-------: | :-------: |
| Ubuntu 22.04 | Jetson Linux 36.4.3 (JetPack 6.2) | 5.15 | √ | 主要维护 |

AIBOX-Orin Nano 搭载NVIDIA 官方原装 Jetson Orin Nano 核心板模组，拥有 8GB 内存，算力高达 67 TOPS，它可以运行所有现代AI模型，包括 Transformer 和 ROS 机器人模型。可以实现更大型、更复杂的深度神经网络，如运用 TENSORFLOW、OPENCV、JETPACK、KERASMXNET、PY-TORCH 等,实现物体识别、目标检测追踪、语音识别、及其他视觉开发等功能，满足更高 AI 人工智能应用场景的需求。
