# 硬件功能使用
## 调试串口

EC-A3399C 整机未引出调试串口接口，需要拆开主机后接入主板 AIO-3399C 上的调试串口，并外接 USB 转 TTL 串口模块进行调试。串口参数为：波特率 1500000、数据位 8、停止位 1、无奇偶校验、无流控。

调试串口的连接方式与使用方法详见：[调试串口](usb_to_ttl.md)。

## 显示接口

AIO-3399C 支持 HDMI 2.0 与 DisplayPort 1.2 两种显示输出接口：

* HDMI 2.0：最高支持 4K@60Hz 输出。
* DisplayPort 1.2：最高支持 4K@60Hz 输出。

支持双屏同显/异显，可在系统的显示设置中配置多屏显示方式。

## 以太网

AIO-3399C 提供 1 个 RJ45 千兆网口，对应系统中的 `eth0` 设备。

网口接入网络后，可以通过调试串口或者 adb 查看 IP 地址：

```
ifconfig eth0
```

连通性测试：

```
ping -I eth0 -c 10 www.baidu.com
```

## USB 接口

AIO-3399C 对外提供以下 USB 接口：

* 1 x USB3.0（后面板）
* 2 x USB2.0（前面板双层 USB 座），可连接鼠标、键盘等 USB 设备
* 1 x Type-C（OTG），主要用于连接主机进行固件烧写

## 串口（RS232 / RS485）

AIO-3399C 前面板提供 1 个 RS232 接口（DB9）和 1 个 RS485 接口（接线端子），常用于对接工业设备：

* RS232：按 DB9 丝印对应关系连接 RXD、TXD、GND 即可。
* RS485：接线时 A 接 A、B 接 B；若通信异常，请检查 A/B 线是否松动或者接反。

简单验证时可短接 RS232 的收发引脚（RS485 短接 A、B），然后在系统内对相应串口设备节点执行 `cat`/`echo` 收发数据（设备节点名称以系统实际识别为准）。机内主板还板载 2 路 TTL 口，需拆开主机后使用。

## TF 卡

AIO-3399C 后面板提供 1 个 TF 卡槽，支持 TF 卡扩展存储；插拔 TF 卡前请先断电。

## SIM 卡

AIO-3399C 的 SIM 卡槽用于配合 Mini PCIe 3G/4G 模块实现移动网络连接。**3G/4G 模块为选配**，需要在机箱内部安装 3G/4G 模块后，SIM 卡功能才能正常使用。SIM 卡插入方向如下图所示，插拔前请先断电。

## 音频

AIO-3399C 前面板提供 1 个 3.5mm Phone 耳机接口，支持音频输出；主板还提供 LINE-IN、LINE-OUT、SPEAKER 等音频接口（需拆机后使用）。

## 红外

AIO-3399C 前面板内置红外接收头，支持红外遥控功能。
