# 接口介绍

AIBOX-PRO-KIT 接口丰富，主要包括：
- 12V 电源接口（5.5*2.1mm）
- Power 按键
- MaskRom 按键
- 千兆以太网 x 2
- USB 3.0 x 2
- Line out & Line in
- HDMI
- TF卡槽
- SIM卡槽
- Type-C（OTG烧录）
- Type-C（Debug）
- RS485
- CAN
- DI/DO 光耦隔离
- 电源指示灯
- Wi-Fi天线 x 2 (需插入对应Wi-Fi模块使用)
- 4G天线（需插入对应4G/5G模块使用）

此外，还支持一个内部的扩展PCIe插槽，一个SATA接口

PS: 如上接口为3588支持，如果核心板使用3576，则硬件上无法使用Wi-Fi、扩展PCIe插槽、SATA模块。
