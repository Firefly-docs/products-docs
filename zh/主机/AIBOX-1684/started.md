## 接口描述

**AIBOX-1684** 提供了丰富的接口，主要包括：

- 12V 电源接口（5.5*2.5mm）
- POWER 按键
- 千兆以太网 x 2
- USB 3.0 x 2
- TF 卡座
- Type C 口（仅作串口使用）
