# 硬件功能使用
## 调试串口

EC-R3328PC 整机未引出调试串口接口，需要拆开主机后接入主板 ROC-RK3328-PC 上的调试串口，并外接 USB 转 TTL 串口模块进行调试。串口参数为：波特率 1500000、数据位 8、停止位 1、无奇偶校验、无流控。

调试串口的连接方式与使用方法详见：[调试串口](usb_to_ttl.md)。

## 显示接口

EC-R3328PC 提供两种显示输出接口：

* HDMI 2.0：支持 4K@60Hz 输出，支持 HDCP 1.4/2.2。
* AV 接口：CVBS 输出，符合 480i、576i 标准，可用于连接老式显示设备。

音频输出支持 HDMI 音频与 AV 音频两种方式。

## 以太网

EC-R3328PC 提供 1 个 RJ45 千兆网口（1000Mbps），对应系统中的 `eth0` 设备。

网口接入网络后，可以通过调试串口或者 adb 查看 IP 地址：

```
ifconfig eth0
```

连通性测试：

```
ping -I eth0 -c 10 www.baidu.com
```

## USB 接口

EC-R3328PC 对外提供以下 USB 接口：

* 1 x USB3.0（限流 1000mA）
* 1 x USB2.0（限流 500mA）
* 1 x Type-C（USB3.0 OTG / DC IN 5V/2A），OTG 方式主要用于连接主机进行固件烧写；供电方式使用 5V/2A Type-C 电源适配器供电

## TF 卡

EC-R3328PC 提供 1 个 TF 卡槽，支持 TF 卡扩展存储；插拔 TF 卡前请先断电。

## 红外与按键

EC-R3328PC 内置红外接收头，支持红外遥控功能；面板上提供 1 个电源按键。
