# 接口介绍

AIBOX-PRO 接口丰富，主要包括：
- 12V 电源接口（5.5*2.1mm）
- Power 按键
- MaskRom 按键
- 千兆以太网 x 2
- USB 3.0 x 2
- Line out & Line in
- HDMI
- TF卡槽
- SIM卡槽
- Type-C（OTG烧录）
- Type-C（Debug）
- RS485
- CAN
- DI/DO 光耦隔离
- 电源指示灯
- Wi-Fi模块/蓝牙模块(同时只能使用一种)
- Wi-Fi天线 x 2
- 4G天线
- 5G天线 x 4

注意：
3576核心板，无法使用：Wi-Fi接口，蓝牙接口（与WiFi接口共用），SATA接口， 扩展PCIe接口
