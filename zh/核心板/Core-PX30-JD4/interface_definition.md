# 接口定义

## 整机接口定义

AIO-PX30-JD4 提供了丰富的接口，主要包括：电源接口， 1 x USB3.0（device），6x USB2.0（接口×4，座子×2），以太网，LVDS屏幕接口，TP触摸接口，屏电压跳线接口，背光接口，WIFI天线，蓝牙天线，电源按键，MIC接口，音频输出(lineout)，3.5mm耳机接口，RTC电源接口，12v电源接口，IR接口，TF卡槽，SIM卡卡槽，喇叭接口，recovery按键，调试串口，工业级串口(单TTL)，MIPI屏接口(单lvds复用)。

#### 特殊接口说明
**MB-JD4-RK3328&PX30底板中的HDMI接口和HUB1_USB3是为了支持RK3328核心板的，所以PX30核心板无法使用这两个接口**
