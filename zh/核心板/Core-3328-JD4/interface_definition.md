
# 接口定义

配套 MB-JD4-RK3328&PX30 底板提供以下主要接口：

* 12V 电源接口
* 1 × USB 3.0 Device
* 5 × USB 2.0（4 个外部接口、1 个板载座子）
* HDMI 显示接口
* 100M 以太网接口
* Wi-Fi 和蓝牙天线接口
* 电源按键、Recovery 按键
* 3.5mm 耳机接口和扬声器接口
* RTC 电池接口
* 红外接收接口
* TF 卡槽和 SIM 卡槽
* 调试串口

## 特殊接口说明

MB-JD4-RK3328&PX30 底板上的 LVDS、TP 触摸、背光、屏电压跳线、MIC 和 MIPI 屏接口用于适配 PX30 核心板，搭配 Core-3328-JD4 时不可使用。
