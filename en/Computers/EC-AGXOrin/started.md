## Interface Description

**EC-AGXOrin** provides rich interfaces, mainly including:

* 1 x DC 24V power interface (5.5mm × 2.1mm, supports 9V~36V wide voltage input)
* 1 x Type-C (Debug serial port)
* 1 x Type-C (OTG)
* 5 x RJ45 Gigabit Ethernet ports (4 of them support PSE power supply)
* 1 x 10Gbps Ethernet port
* 4 x USB3.0 (current limit 1A)
* 1 x HDMI2.0 (supports 4K@60Hz output)
* 8 x GMSL2
* 1 x TF Card
* 1 x SIM card slot
* 1 x 3.5mm Audio Jack (supports MIC recording, CTIA standard)
* 1 x 24Pin Phoenix terminal block (3.5mm pitch, including 2 x CAN, 1 x RS485, 1 x RS232, 1 x UART and IO)
* 2 x WiFi antenna, 3 x 5G antenna, 1 x 4G/5G antenna, 1 x GPS antenna
* Power key, Reset key, Recovery key
* Working LED, Power LED

The positions and silkscreen definitions of the interfaces are shown in the figures above.
