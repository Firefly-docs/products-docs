# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-R3399PC_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-r3399pc) | [Downloads](https://community.t-firefly.com/en/doc/download/)


The EC-R3399PC Mini PC is based on the high-performance open-source ROC-RK3399-PC platform, with an industrial enclosure, dust and interference prevention, and long-term stable operation. It supports 4K hardware decoding. Equipped with the Rockchip RK3399 six-core processor, it uses a "server-grade" big.LITTLE architecture (dual-core Cortex-A72 + quad-core Cortex-A53) with a main frequency of up to 1.8GHz, supports OpenGL ES1.1/2.0/3.0/3.1, and has a built-in VPU video processor.

## Interface Description

**EC-R3399PC** provides rich interfaces, mainly including:

* 1 x DC 12V power interface (5.5mm x 2.1mm, supporting 9V-24V wide voltage input)
* 1 x RJ45 (Gigabit Ethernet)
* 1 x HDMI 2.0 (4K@60fps output)
* 1 x USB-C multi-function interface (USB3.0 OTG data transfer, DP1.2 video output up to 4K@60fps)
* 1 x USB3.0 (current limit 1A)
* 1 x USB2.0 (current limit 500mA)
* 1 x TF Card
* 1 x 3.5mm audio jack (supports MIC recording)
* 1 x WiFi antenna (dual-band 2.4GHz/5GHz WiFi, 802.11 a/b/g/n/ac, Bluetooth 5.0)
* IR remote control supported
* 1 x Power button, 1 x Recovery button (at the end of the audio jack)

Dual-display is supported: 1 x USB-C (2K output) + 1 x HDMI (4K output). The motherboard inside also provides 1 x PCIe2.1 (2 Lanes, expandable with a 2242 NVMe SSD).
