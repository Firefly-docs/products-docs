The EC-R3588SPC embedded computer is based on the high-performance open-source ROC-3588S-PC platform. It runs stably for a long time, supports 8K encoding and decoding, and its rich interfaces make it easy to connect to various industrial devices. It adopts the Rockchip RK3588S, a new-generation octa-core 64-bit processor, and can be configured with up to 32GB of super-large memory. It supports 8K video encoding and decoding, Gigabit Ethernet, dual-band WiFi and 4G LTE; with rich interfaces such as RS485, RS232 and CAN, it is suitable for edge computing, artificial intelligence, smart home, smart retail, smart industry and other fields.

## Interface Description

**** provides rich interfaces, mainly including:

* 1 x HDMI2.1 (up to 8K@60Hz output)
* 1 x USB3.0 OTG (Type-C)
* 1 x Display Port 1.4 (up to 8K@30Hz output)
* 1 x 4G LTE
* 1 x SIM card slot
* 1 x CAN
* 3 x RS232
* 2 x RS485
* 1 x SATA3.0 or PCIe2.0
* 1 x RELAY (relay output)
* 1 x INPUT (optocoupler isolated input)
* 3 x LED (one tri-color LED, two single-color LEDs)
* 1 x TF Card
* 1 x USB3.0
* 1 x USB2.0
* 1 x WIFI
* 1 x Bluetooth
* 2 x RJ45 (one supports 1Gbps, one supports 100Mbps)
* 1 x 3.5mm headphone jack
