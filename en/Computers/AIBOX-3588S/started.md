# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/AIBOX-3576_AIBOX-3588_AIBOX-3588S_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/aibox-3588s-embedded-fanless-pc) | [Downloads](https://community.t-firefly.com/en/doc/download/324)

**AIBOX-3588S** is equipped with the Rockchip octa-core 64-bit processor RK3588S. It adopts an advanced process technology with high performance and low power consumption, has a built-in ARM Mali-G610 MP4 quad-core GPU, and integrates a 6 TOPS NPU. It supports the private deployment of ultra-large-parameter models under the Transformer architecture, supports traditional network architectures such as CNN, RNN, and LSTM, supports multiple deep learning frameworks, supports custom operator development, and supports Docker container management technology. One box can meet personalized AI deployment.

## Interface Description

**AIBOX-3588S** provides rich interfaces, mainly including:
- 12V power interface (5.5*2.5mm)
- Power button
- MaskRom button
- Gigabit Ethernet x 1
- USB 3.0 x 2
- PCIE/SATA SSD slot (at the bottom of the device) x 1
- HDMI
- TF card slot
- Console (Debug Serial)
- Type-C USB2.0 (for flashing)
- Power indicator LED
