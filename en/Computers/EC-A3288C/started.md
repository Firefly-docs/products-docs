# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-A3288C_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-a3288c-quad-core-mini-embedded-computer) | [Downloads](https://community.t-firefly.com/en/doc/download/58)

The EC-A3288C adopts the RK3288 quad-core Cortex-A17 processor, clocked at up to 1.8GHz, integrated with a quad-core Mali-T764 GPU, and supports 4K hardware decoding, achieving 4Kx2K H.264 and H.265 video hardware decoding and dual-screen identical/differential display. The rich expansion interfaces meet different practical needs of customers. The beautiful aluminum alloy casing makes the product more perfect and simple, and the integrated overall design greatly shortens the customer development period. It is a low-threshold, high-efficiency development product, widely used in game equipment, advertising machines, vending machines, robots and other scenarios.

## Interface Description

**EC-A3288C** provides rich interfaces, mainly including:

* Debug serial port (UART2, TTL level, corresponding to the system node `/dev/ttyS2`)
* 1 x RS485 (corresponding to the system node `/dev/ttyS1`)
* 1 x RS232 (corresponding to the system node `/dev/ttyS3`)
* Display output: supports dual-screen identical/differential display, and the SDK provides the firmware configuration for LVDS display output

Other external interfaces (Ethernet, USB, etc.) are subject to the actual product.
