# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-A3399ProC_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-a3399proc-six-core-64-bit-ai-embedded-computer) | [Downloads](https://community.t-firefly.com/en/doc/download/77)

The EC-A3399ProC is a six-core 64-bit AI embedded host based on the AIO-3399ProC artificial intelligence open-source platform. It is equipped with an industrial-grade metal casing with efficient heat dissipation, supports multiple operating systems, runs stably, and has super AI computing performance and rich expansion interfaces. The CPU integrates an AI neural network processor (NPU) supporting 8-bit/16-bit computing with a performance of up to 3.0 TOPS, and provides the Rock-X SDK AI visual recognition API component library for rapid machine vision recognition. It supports TensorFlow/Caffe/Mxnet general models, the Android NN API, the RKNN cross-platform API, and the TensorFlow development interface, and provides AI development tools such as model conversion and on-device conversion APIs.

The EC-A3399ProC has powerful hardware encoding and decoding capabilities, supporting 4K VP9, 4K 10-bit H265/H264, and 1080P multi-format (VC-1, MPEG-1/2/4, VP8) video decoding. Abundant expansion interfaces meet different actual needs of customers, and the integrated overall design greatly shortens the customer development cycle.

## Interface Description

**EC-A3399ProC** provides rich interfaces, mainly including:

* 1 x DC 12V power interface (DC 5.5 x 2.1mm)
* 1 x RJ45 (Gigabit Ethernet)
* 1 x HDMI 2.0 (up to 4K@60Hz output, HDCP 1.4/2.2 supported)
* 1 x Type-C (OTG, can be used for firmware flashing)
* 1 x USB3.0
* 2 x USB2.0 (dual-stacked USB recepts on the front panel)
* 1 x RS232 (DB9)
* 1 x RS485 (terminal block, sharing the same connector with CAN)
* 1 x TF Card
* 1 x Micro SIM card slot (used with a Mini PCIe 3G/4G module, module optional)
* 1 x 3.5mm Phone jack
* 2 x WiFi/Bluetooth antennas (ANT)
* 1 x IR receiver
* 1 x Power button
