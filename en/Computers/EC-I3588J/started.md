# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-I3588J_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-i3588j-8-core-8k-computer) | [Downloads](https://community.t-firefly.com/en/doc/download/167)


The EC-I3588J embedded host is based on the ITX-3588J high-performance open-source platform, equipped with industrial grade casing, dustproof and anti-interference, stable operation for long time, supporting 8K encoding and decoding, and rich interfaces for easy connection to various industrial devices.
Based on Rockchip's all-new flagship AIoT chip -- **RK3588**, it adopts an 8nm LP process; Equipped with an eight core (Cortex-A76 x 4+Cortex-A55 x 4) 64 bit CPU, with a main frequency of up to 2.4 GHz. Integrated ARM Mali-G610 MP4 quad core GPU with built-in AI accelerator NPU, capable of providing 6 Tops of computing power, supporting mainstream deep learning frameworks.

## Interface Description

**** provides rich interfaces, mainly including:

* 1 x HDMI2.1 (max output support 8K@60Hz)
* 1 x HDMI2.0
* 1 x HDMIIN2.0 (max input support 4K@60Hz)
* 1 x Display Port1.4 (max output support 8K@30Hz)
* 1 x USB3.0 OTG (Type-C)
* 1 x VGA
* 2 x MIPI-DSI
* 1 x MIPI-CSI
* 4 x SATA3.0
* 1 x M.2 (SATA3.0)
* 1 x PCIe3.0x4
* 1 x TF Card
* 1 x 4G LTE
* 1 x 5G mobile network
* 1 x SIM card slot
* 4 x USB3.0
* 4 x USB2.0
* 1 x WIFI (support wifi6)
* 1 x Bluetooth
* 1 x FAN (V1.1 version and subsequent versions are 4 PIN, controlled by PWM with ADC detection)
* 2 x RJ45 (support 1Gbps)
* 1 x Speaker
* 1 x Line-In
* 1 x RS485
* 1 x RS232
* 1 x CAN (added in V1.1 version; the H and L markings are reversed in V1.1, and the silkscreen is correct for V1.2 and subsequent versions)
* Multiple power input interfaces
