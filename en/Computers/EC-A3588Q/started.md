# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-A3588Q_EC-A3588JQ_EC-A3588MQ_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-a3588q-rockchip-rk3588-octa-core-8k-ai-industrial-computer) | [Downloads](https://community.t-firefly.com/en/doc/download/202)

The EC-A3588Q adopts the Rockchip RK3588 octa-core 64-bit processor and can be configured with up to 32GB of super-large memory; it supports 8K video encoding and decoding; it has rich interfaces, supporting Gigabit Ethernet, WiFi6, 5G/4G expansion, a variety of video input and output, and M.2 SATA/PCIe solid state drives; it supports multiple operating systems; it can be used in ARM PC, edge computing, industrial control, IoT gateway, cloud terminal, smart vehicle and other fields.

## Interface Description

**** provides rich interfaces, mainly including:

* 1 x DC 12V power interface (5.5mm × 2.1mm)
* 1 x Mic (microphone input)
* 1 x 3.5mm Audio Jack
* 2 x RJ45 (1000Mbps)
* 4 x USB3.0 (Gen1)
* 1 x USB-C (supports DP1.4)
* 1 x HDMI2.1 (up to 8K output)
* 1 x HDMI-IN
* 1 x VGA
* 1 x TF Card
* 1 x SIM card slot
* 1 x CAN
* 2 x RS232
* 1 x RS485
