# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-A3588JD4_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-a3588-jd4-6tops-ai-host-large-model-8k-decoding-edge-computing-ruixin-micro-rk3588) | [Downloads](https://community.t-firefly.com/en/doc/download/285)


The EC-A3588JD4 is an embedded host based on the high-performance AIO-3588JD4 open-source platform. With an industrial-grade enclosure, it is dust-proof and anti-interference, runs stably for a long time, supports 8K encoding and decoding, and its rich interfaces make it easy to connect various industrial devices.
It is based on Rockchip's new-generation flagship AIoT chip -- **RK3588**, which adopts the 8nm LP process; it is equipped with an octa-core (Cortex-A76 x 4 + Cortex-A55 x 4) 64-bit CPU with a frequency of up to 2.4 GHz. It integrates an ARM Mali-G610 MP4 quad-core GPU and a built-in AI accelerator NPU, which can provide 6 Tops of computing power and supports mainstream deep learning frameworks.
