# Introduction

[Specification](https://download.t-firefly.com/Spec/Computers/EC-A3588L_Specification_EN.pdf) | [Purchase](https://www.t-firefly.com/products/ec-a3588l-flagship-ai-computer-powered-by-the-rockchip-rk3588-series) | [Downloads](https://community.t-firefly.com/en/doc/download/249)

The EC-A3588L is an embedded host based on the high-performance AIO-3588L open-source platform. With an industrial-grade enclosure, it is dust-proof and anti-interference, runs stably for a long time, supports 8K encoding and decoding, and its rich interfaces make it easy to connect various industrial devices.
It is based on Rockchip's new-generation flagship AIoT chip -- **RK3588**, which adopts the 8nm LP process; it is equipped with an octa-core (Cortex-A76 x 4 + Cortex-A55 x 4) 64-bit CPU with a frequency of up to 2.4 GHz. It integrates an ARM Mali-G610 MP4 quad-core GPU and a built-in AI accelerator NPU, which can provide 6 Tops of computing power and supports mainstream deep learning frameworks.

## Interface Description

**** provides rich interfaces, mainly including:

* 1 x HDMI (8K output)
* 1 x HDMI-IN (HDMI input)
* 1 x Type-C
* 2 x USB 3.0
* 1 x RJ45 (Gigabit Ethernet)
* 1 x TF card slot
* 1 x SIM card slot (with 4G module)
* 1 x DC 12V power input
* Antenna connectors: BT/WB, 4G, WIFI
* Power button
