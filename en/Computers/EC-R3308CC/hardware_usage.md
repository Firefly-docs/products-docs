# Hardware Function Usage
## Debug Serial Port

The debug serial port of the EC-R3308CC is UART4. The serial port parameters are: baud rate 1500000, 8 data bits, 1 stop bit, no parity, no flow control.

The debug serial port is a TTL-level interface. An external USB to TTL serial module is required for debugging. Note that some USB to serial chips cannot reach the baud rate of 1500000. Please confirm whether the USB to TTL module you use supports it before purchasing.

For the connection and usage of the debug serial port, please refer to: [Debug Serial Port](usb_to_ttl.md).

## Other Interfaces

The usage of other external interfaces of the EC-R3308CC is to be supplemented, subject to the actual system.
