# Introduction

[Specification](（同中文版）) | [Purchase](https://www.t-firefly.com/products/station-p1-pro-mini-pc-ce-fcc-rohs) | [Downloads](https://community.t-firefly.com/en/doc/download/216)

The Station P1 Pro Geek Mini PC is based on the high-performance open-source ROC-RK3399-PC Pro platform, with an industrial enclosure, dust and interference prevention, and long-term stable operation. It supports 4K hardware decoding. Equipped with the Rockchip RK3399 six-core processor, it uses a "server-grade" big.LITTLE architecture (dual-core Cortex-A72 + quad-core Cortex-A53) with a main frequency of up to 1.8GHz, supports OpenGL ES1.1/2.0/3.0/3.1, and has a built-in VPU video processor.

## Interface Description

**Station P1 Pro** provides rich interfaces, mainly including:

* 1 x DC 12V-2A power interface (5.5*2.1mm)
* 1 x RJ45 (Gigabit Ethernet, 1000Mbps)
* 1 x HDMI 2.0 (4K@60Hz output)
* 1 x USB-C (USB3.0 / OTG / DP1.2, DP1.2 up to 4K@60Hz output)
* 1 x USB3.0 (current limit 1000mA)
* 1 x USB2.0 (current limit 500mA)
* 1 x TF Card
* 1 x 3.5mm Audio Jack (supports Mic recording; the Recovery button is inside the audio jack)
* 1 x WiFi antenna (dual-band 2.4GHz/5GHz WiFi, 802.11 a/b/g/n/ac, Bluetooth 5.0)
* 1 x IR receiver
* 1 x Power button

Dual-display is supported: DP1.2 (2K output) + HDMI (4K output). The motherboard inside also provides 1 x PCIe2.1 NVMe SSD (2242) expansion.
