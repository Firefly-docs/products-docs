# Introduction

The **CQ38W-1126B** is powered by the Rockchip quad-core AI vision processor RV1126B, integrating a 3 TOPS NPU that efficiently supports intelligent applications such as facial and gesture recognition. For imaging, it features a built-in 16MP ISP, supports 4K@120fps decoding and 4K@60fps encoding, and is paired with a 5MP/3MP HD camera to accurately capture details even in low-light environments. The device adopts an IP67 waterproof aluminum alloy housing and supports PoE, requiring only a single network cable for both power and data transmission. Easy to deploy, it is suitable for various scenarios including access control gates and smart security.
