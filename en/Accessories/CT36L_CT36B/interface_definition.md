# Interface definition

## Complete machine interface definition

**CT36L** provides the following interfaces, mainly including:

* 1 x MIPI-CSI
* 1 x MIC (reserved interface)
* 1 x SPK (reserved interface)

**CT36B** provides the following interfaces, mainly including:

* 1 x MIPI-CSI
* 1 x MIC (reserved interface)
* 1 x LINE_OUT(reserved interface)
