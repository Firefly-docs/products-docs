# Interface Definition

## Interface Definition

Firefly-RK3128 provides a lot of interfaces, which include HDMI, digital optical, ethernet, DC power interface, reset button, power button, recovery button, audio input/output, silicon microphone, serial debug interface, IR receiver, OTG interface, TF card slot, USB Host1~4, WIFI antenna, CSI camera interface, and two rows of expansion interfaces. All are shown below.
