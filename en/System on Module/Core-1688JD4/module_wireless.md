# Wireless Modules
The communication modules supported by Firefly are as follows:
- [WXT14R2201 WiFi/BT Module](https://community.t-firefly.com/en/docs/products/accessories/WXT14R2201/started)
- [WCT1FR2201 WiFi/BT Module](https://community.t-firefly.com/en/docs/products/accessories/WCT1FR2201/started)
- [EC20 4G-LTE Module](https://community.t-firefly.com/en/docs/products/accessories/EC20/started)
- RM500U-CN 5G Module
