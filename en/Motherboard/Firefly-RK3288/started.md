# Introduction

* Firefly-RK3288
    + Firefly-RK3288 development board × 1
    + WiFi antenna
    + Acrylic rack (to protect board)

* Firefly-RK3288-Reload
    + Firefly-RK3288-Reload floor x 1
    + Core-3288J core board x 1
    + WiFi antenna

Other optional accessories:

* [5V/3A DC power adapter (support 220V/110V input)](https://www.firefly.store/products/5v-3a-power-adapter)  
* [Firefly serial port module](https://www.firefly.store/products/usb-to-uart-module-cp2104)  

In addition, you may need the following accessories during use:

* Display device
    + Display or TV which supports VGA interface, and VGA cable
    + Monitor or TV with HDMI interface and HDMI cable
* Network
    + 100M/1000M Ethernet cable, and wired router
    + WiFi router
* Input devices
    + USB wire/wireless mouse/keyboard
    + Infrared remote control (need to connect to the infrared receiver)
* Firmware upgrade and debugging
    + Micro USB cable
    + Serial to usb adapter
